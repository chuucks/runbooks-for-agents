# runbooks-for-agents
A versioned Agent Skills for everyday productivity and engineering work.
--

A personal, growing library of Agent Skills that turn one-off prompts into repeatable procedures. The repo spans two lanes: general-purpose productivity skills (writing, research, planning, docs) and technical skills for hands-on engineering work (code review, debugging, root-cause troubleshooting, and architecture triage). Each skill is treated like any other code artifact: versioned, tested, and built to hold up when an agent runs it unattended, not just when a human is watching.
